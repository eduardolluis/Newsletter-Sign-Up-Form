# Newsletter Sign-Up Form

A responsive newsletter sign-up interface built with HTML, CSS, and JavaScript.

## Features

- Email input form
- Client-side form handling
- Success-state interface
- Responsive desktop layout
- Custom SVG assets

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Run Locally

```bash
git clone https://github.com/eduardolluis/Newsletter-Sign-Up-Form.git
cd Newsletter-Sign-Up-Form
```

Open `index.html` in your browser.
